## 1. The Strategy: How Developers Actually Adopt Software

Most developer launches struggle because marketing teams treat developers like enterprise buyers: they write press releases, buy sponsored ads, and force visitors into qualification calls.

Developers prefer discovering **unbloated tools that solve a specific engineering bottleneck immediately**.

This launch kit outlines a four-stage developer marketing framework:
1. **Show HN Launch Post:** Written engineer-to-engineer with zero corporate buzzwords, architectural vulnerability, and runnable reproduction steps.
2. **High-Conversion Landing Page Wireframe:** Centered around a single-line terminal command and real-time telemetry metrics.
3. **4-Part Technical Onboarding Drip:** High-signal email sequence that explains kernel mechanics rather than pitching upsells.
4. **Technical Release Notes:** Crisp changelog detailing breaking API shifts and performance optimizations.

## 5. Strategic Distribution & Packaging Principles

- **Zero Corporate Jargon:** Avoid words like "streamline", "unleash", or "paradigm".
- **Runnable First Steps:** Every launch post must lead with how to run or inspect the code locally.
- **Audited Architecture:** Detailed explanations of trade-offs build higher credibility than unverified perfection claims.
